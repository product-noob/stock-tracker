⚖️ Global invariants (never violate)

#Rule
1Exact bytes before parsing — persist + SHA-256 register every response first. JSONB is a query aid, never truth.
2Idempotent writes at every stage — at-least-once delivery must never duplicate logical results.
3Append-only evidence — corrections supersede via new rows; DB triggers reject update/delete.
4The LLM extracts; code decides — severity/ranking/classification are deterministic versioned code; model confidence never trusted.
5Identity fails closed — ambiguity → review queue; fuzzy may suggest, only exact publishes; adapters preserve raw fields.
6Exchange category ≠ event kind — separate vocabularies.
7Cursors advance only after artifact + items commit; overlap polling everywhere.
8HTTP 200 proves nothing — magic-byte validation always (AttachLive trap).
9Causal language gated — “fell after filing”: yes. “Caused”: never.
10Terminology: capture/fetch = network retrieval; extraction = LLM stage only.
11UTF-8 explicitly everywhere — cp1252 broke on ₹.
