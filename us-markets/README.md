# US Markets Tracker

Daily pre-market briefs, mid-session sudden-move alerts, close recaps, and a weekly
fundamental + technical letter for Prince's US equity holdings and watchlist.

- **Holdings:** GOOGL, NVDA, AAPL, MSFT
- **Watchlist:** AAPL, META, TSM, ASML, AMZN

## Layout

- `briefs/` — daily updates: `YYYY-MM-DD-premarket.md`, `YYYY-MM-DD-midsession.md`, `YYYY-MM-DD-close.md`
- `weekly/` — weekly letters: `YYYY-Www-weekly-letter.md`
- `data/state.json` — last known prices, earnings dates, alert history

This content is analysis for personal use, not financial advice.
